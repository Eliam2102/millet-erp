# Validation quickstart
En frontend: npm ci; npm run test -- src/components/erp/data; npm run build; npm run lint. Ejecutar regresiones de los hooks y páginas migradas.
En navegador local con datos ficticios: 390×844,1366×768,1920×1080; variar auto/10/20/50/100, recargar y volver; filtros y vacío; última página; almacenamiento denegado; columnas anchas y teclado. Caso remoto: verificar limit/offset de solicitudes y total exacto. Caso formulario: editar, redimensionar y comprobar captura. Reporte: exportación completa independiente de página.
